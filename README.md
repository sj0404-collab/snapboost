# SnapBoost

Диагностический оверлей для телефонов со Snapdragon. Показывает **реальные** FPS,
frametime, троттлинг CPU и GPU, температуры, давление на ресурсы и состояние
аудиотракта — и подсказывает, что именно ломает звук в играх вроде Genshin Impact.

Приложение ничего не «разгоняет» в прямом смысле. Оно измеряет, что мешает
смартфону, и применяет те меры, которые Android позволяет применить легально.

---

## Что это решает

Главная жалоба в мобильных играх на Snapdragon: звук «рычит», рвётся, не
вывозит спецэффекты. Причина почти всегда одна — **аудиобуфер не успевает
наполняться**. Игровой `AudioTrack` отдаёт данные с задержкой, общий буфер
опустошается, HAL не успевает его перезаполнить, и в выходе появляются щелчки
и пропуски.

Причин у этого несколько, и SnapBoost показывает, какая именно у вас:

| Причина | Как приложение это видит | Что делать |
|---|---|---|
| Звук идёт по Bluetooth A2DP | маршрут вывода определяется через `AudioManager` | выключить Bluetooth или взять проводные наушники |
| Системный DSP (Dolby Atmos, Dirac, Histen) | следы surround-обработки в `dumpsys audio` | отключить surround (`cmd audio`) |
| Пересчёт частоты в HAL | расхождение `PROPERTY_OUTPUT_SAMPLE_RATE` и частоты HAL | убрать системные эффекты |
| Троттлинг из-за нагрева | `scaling_max_freq` против `cpuinfo_max_freq`, thermal-статус, headroom | охладить, снять чехол, отключить зарядку |
| Простои ресурсов | `/proc/pressure/*` (PSI) — доля времени, когда задачи ждали | закрыть фоновые процессы |
| Чужое приложение держит аудио-фокус | стек `Audio Focus` из `dumpsys audio` | закрыть приложение или включить «Не беспокоить» |

## Откуда берутся данные

Главный принцип: **`N/A` вместо выдуманного числа**. Подставной FPS в
мониторе опаснее отсутствующего — по нему принимают решения о настройке железа.

Источники по уровням доступа:

**Без привилегий (всегда доступны)**
- `/sys/devices/system/cpu/cpu*/cpufreq/*` — текущая частота, потолок, governor
- `/sys/class/kgsl/kgsl-3d0/*` — **KGSL, интерфейс Qualcomm для Adreno**:
  `gpu_busy_percentage`, `gpu_clockfreq`, `max_gpuclk`, узлы троттлинга
- `/sys/class/thermal/thermal_zone*` — температуры по зонам
- `/proc/pressure/{cpu,memory,io}` — PSI, самый прямой измеритель «фризов»
- `/proc/<pid>/stat` — реальные CPU% и RSS процесса игры
- `AudioManager.getProperty()` — частота вывода и размер буфера
- `AudioManager.getDevices()` — физический маршрут вывода
- `Choreographer` — частота обновления дисплея

**С правами shell (нужен Shizuku)**
- `dumpsys SurfaceFlinger --latency` — **настоящие FPS** и frametime
- `dumpsys media.audio_flinger` — **счётчик underrun**, задержка, число потоков
- `dumpsys audio` — стек аудио-фокуса, surround, активное устройство
- `dumpsys gfxinfo` — процент jank по измеренному окну
- `settings put global` — анимации
- `cmd audio set-surround-format-enabled` — отключение объёмного звука

`dumpsys` требует `android.permission.DUMP`, которого у обычного приложения нет.
Без Shizuku эти метрики показываются как `N/A` — и это указано в интерфейсе,
а не замаскировано.

## Установка

1. Скачайте `snapboost-release.apk` из релизов.
2. Разрешите установку из неизвестных источников.
3. `adb install -r snapboost-release.apk`
4. В приложении выдайте **«Отображение поверх других приложений»** — без этого
   оверлей не появится, мониторинг продолжит работать.
5. Для настоящих FPS и счётчика потерь аудио поставьте [Shizuku](https://shizuku.rikka.app/),
   запустите его и вернитесь в приложение.

## Использование оверлея

- **Короткое нажатие** — переключение режимов: полный → минимальный → выключен
- **Перетаскивание** — перемещение по экрану
- **Долгое нажатие** — открыть панель настроек

## Осознанные ограничения

В приложении **нет** и не планируется:

- снятия тепловых лимитов (thermal governor) — это не буст, а ускоренный
  износ SoC; Snapdragon от такого теряет производительность навсегда
- записи в `cpufreq` и KGSL — нужно root, ломает гарантию и ухудшает стабильность
- модификации памяти игр, инжекта нативных библиотек, эмуляции ввода,
  обхода античита — это читы: нарушение условий игры и угроза бану аккаунта
- «мгновенного +40 FPS». Такого не существует: производительность упирается в
  нагрев и расчёт GPU, а не в настройки

## Сборка из исходников

```bash
./gradlew assembleRelease
```

APK попадёт в `app/build/outputs/apk/release/`.

Релизная сборка подписана ключом из репозитория
(`keystore/release.jks`, store/key password: `snapboost`). Он лежит в репозитории
намеренно, чтобы любой мог собрать APK из исходников. Для собственного
распространения замените его своим ключом в `app/build.gradle.kts`.

## Требования

- Android 10 (API 29) и выше
- compileSdk 35, AGP 8.7.3, Kotlin 2.0.21, Jetpack Compose
